Name of Projcet : DevStack 

Description :
DevStack is a modern, lightweight technology stack explorer that helps developers discover, filter, and curate their favorite tools and technologies into a personalized tech stack.

Frontend: React, TypeScript
Styling: Tailwind CSS
Icons & Notifications: React Icons, React-Toastify
Data Fetching: JSON (for technology data)
Vite (build tool)

Features :
1. Interactive Stack Management: Easily add or remove technologies from your personal stack with real-time dynamic button state updates.

2. Responsive Mobile-First UI: Navigation across devices featuring a desktop navbar, a mobile hamburger menu, and an adaptive layout.

3. Instant Feedback & Notifications: Built-in Toast notifications and state validation to  duplicate items and provide immediate feedback on user actions.
